# rich-monitor

Automated monitoring and diagnostics for
[RICH](https://gitlab.com/rich-hydro/rich) moving-mesh radiative hydrodynamic
simulation runs, currently applied to runs on the Netherlands national computing
cluster
[Snellius](https://www.surf.nl/en/dutch-national-supercomputer-snellius). 

Currently there are many places with hardcoded path on snellius, and for my file
structures. Future updates will come to improve the portability. Before that,
please read the script and modify the paths and parsing of paths
accordingly. But anytime if you have any question, feel free to shoot me an
email [yujiehe@strw.leidenuniv.nl](mailto:yujiehe@strw.leidenuniv.nl).
